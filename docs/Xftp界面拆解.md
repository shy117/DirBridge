# Xftp界面拆解

关联：[[XFolder]]、[[架构草案]]、[[第一阶段功能范围]]

## 目标界面

XFolder 的第一版界面参考 Xftp：本地文件和服务器端文件同时显示，用户可以在本地与远程之间、不同远程目录之间拖拽文件，底部显示传输队列和日志。

核心不是单个远程目录浏览器，而是多目录文件管理器。

## 主窗口区域

主窗口分为四个区域：

1. 顶部菜单栏和工具栏
2. 左侧会话管理器
3. 中间文件管理区
4. 底部传输和日志区

### 顶部区域

顶部区域包含：

- 菜单栏：文件、编辑、查看、命令、工具、窗口、帮助。
- 工具栏：新建会话、打开会话、断开、刷新、返回、前进、设置等。
- 快速连接栏：协议、主机、端口、用户名、密码、连接按钮。

第一版可以先简化为菜单栏、常用工具栏、快速连接栏，不必完全复刻所有图标。

### 会话管理器

会话管理器用于保存常用连接：

- 所有会话
- 分组
- 会话条目
- 搜索
- 新建、编辑、删除、连接

第一版会话字段：

- 名称
- 协议：FTP、FTPS、SFTP
- 主机
- 端口
- 用户名
- 密码
- 默认远程路径
- 编码

密码第一版可先明文保存，但必须在文档和 UI 中标注限制，后续再接 Windows Credential Manager。

### 文件管理区

默认布局：

- 左侧：本地文件面板
- 右侧：远程文件面板

每个面板包含：

- 标签页
- 路径工具条
- 文件表格
- 状态栏

本地面板字段：

- 名称
- 大小
- 类型
- 修改时间

远程面板字段：

- 名称
- 大小
- 类型
- 修改时间
- 权限
- 所有者
- 组

远程侧必须支持多个标签页。一个标签页可以是一个远程会话，也可以是同一会话下打开的不同目录。

后续增强：

- 支持远程标签组并排显示。
- 支持本地多标签。
- 支持标签拖拽重排。

### 底部区域

底部区域至少有两个标签：

- 传输
- 日志

传输列表字段：

- 名称
- 状态
- 进度
- 大小
- 本地路径
- 远程路径
- 方向
- 速度
- 剩余时间
- 错误信息

传输操作：

- 暂停
- 继续
- 取消
- 重试
- 清除完成项

## 拖拽行为

拖拽是 XFolder 的核心工作流。

### 本地到远程

用户从本地面板拖文件到远程面板：

- 拖到目录行：上传到该目录。
- 拖到空白区域：上传到当前远程目录。
- 拖到远程标签页：上传到该标签页当前目录。

### 远程到本地

用户从远程面板拖文件到本地面板：

- 拖到目录行：下载到该目录。
- 拖到空白区域：下载到当前本地目录。
- 拖到本地标签页：下载到该标签页当前目录。

### 远程到远程

用户从远程 A 拖到远程 B：

- 第一版默认走本地临时中转。
- 任务在底部传输队列中显示为远程到远程。
- 成功后清理临时文件。
- 任一步失败都保留清晰错误。

### 同一面板内部

同一目录内部拖拽：

- 第一版可以先不启用复杂移动。
- 后续再根据 Ctrl/Shift 键区分复制和移动。

## 第一版界面取舍

先做：

- 左本地、右远程双栏。
- 远程多标签。
- 会话管理器。
- 底部传输队列和日志。
- 拖拽上传、下载、跨远程中转。

暂缓：

- 多标签组并排。
- 完整菜单命令。
- 远程编辑。
- 同步文件夹。
- 终端集成。
