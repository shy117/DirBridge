# 运行环境说明

关联：[[XFolder]]、[[CMake依赖方案]]

## 目标

`build/run` 是本地可直接运行目录，用于快速验证当前构建产物。它不提交到 Git，随时可以重新生成。

当前可执行文件：

```text
E:\Workspace\Project\XFolder\build\run\XFolder.exe
```

## 生成步骤

先构建 Debug 版本：

```powershell
cmake --preset windows-mingw-debug
cmake --build --preset windows-mingw-debug
```

创建运行目录并复制 XFolder 与 libcurl 运行文件：

```powershell
New-Item -ItemType Directory -Force build\run
Copy-Item -Force build\windows-mingw-debug\XFolder.exe build\run\XFolder.exe
Copy-Item -Force build\windows-mingw-debug\libcurl-x64.dll build\run\libcurl-x64.dll
Copy-Item -Force build\windows-mingw-debug\curl-ca-bundle.crt build\run\curl-ca-bundle.crt
```

使用 `windeployqt` 补齐 Qt 和 MinGW 运行库：

```powershell
$env:PATH='D:\QT\6.8.0\mingw_64\bin;D:\QT\Tools\mingw1310_64\bin;' + $env:PATH
D:\QT\6.8.0\mingw_64\bin\windeployqt.exe --compiler-runtime --no-translations build\run\XFolder.exe
```

## 验证命令

在运行目录中直接执行，不额外设置 Qt 路径：

```powershell
Set-Location E:\Workspace\Project\XFolder\build\run
.\XFolder.exe --check-curl
.\XFolder.exe --smoke-test
```

`--check-curl` 应输出 libcurl 协议列表，并包含：

```text
ftp
sftp
```

`--smoke-test` 应能启动空 Qt 窗口并自动退出。

## Git 策略

`build/` 和 `third_party/` 已在 `.gitignore` 中排除：

```text
build/
third_party/
```

因此运行目录和下载的二进制依赖都不提交，只提交构建脚本、源码和文档。
