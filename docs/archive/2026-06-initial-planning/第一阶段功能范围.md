# 第一阶段功能范围

关联：[[XFolder]]、[[Xftp界面拆解]]、[[架构草案]]

## 目标

第一阶段目标是做出 Xftp 风格的最小可用远程文件管理工具。

必须能完成：

- 本地目录浏览。
- FTP/SFTP 远程目录浏览。
- 本地和远程之间拖拽上传下载。
- 多远程标签之间拖拽传输。
- 底部传输队列显示进度和状态。

## 必做功能

### 主界面

- 菜单栏。
- 工具栏。
- 快速连接栏。
- 左侧会话管理器。
- 中间左右双栏文件面板。
- 底部传输和日志标签页。

### 本地文件面板

- 显示本地目录。
- 返回、前进、上级、刷新。
- 路径输入跳转。
- 文件排序。
- 新建目录。
- 删除。
- 重命名。
- 拖拽发起和接收。

### 远程文件面板

- FTP 连接。
- SFTP 连接。
- 远程目录列表。
- 返回、前进、上级、刷新。
- 路径输入跳转。
- 新建目录。
- 删除。
- 重命名。
- 多远程标签页。

### 传输

- 本地到远程上传。
- 远程到本地下载。
- 远程到远程中转传输。
- 文件夹递归传输。
- 多任务队列。
- 进度、速度、状态、错误信息。
- 取消和重试。

### 会话管理

- 新建会话。
- 编辑会话。
- 删除会话。
- 保存常用连接。

## 暂缓功能

- 远程文件编辑后自动上传。
- 文件夹同步。
- SSH 终端。
- FTP FXP 服务器直传。
- 复杂权限编辑器。
- 断点续传 UI。
- 密码加密保存。
- 多标签组并排。
- 远程搜索。

## 验收场景

### 场景 1：连接远程服务器

用户在快速连接栏输入协议、主机、端口、用户名、密码，点击连接。系统打开一个远程标签页并显示远程目录。

### 场景 2：上传文件

用户从左侧本地面板拖一个文件到右侧远程面板。系统在底部传输队列创建上传任务，显示进度，完成后刷新远程目录。

### 场景 3：下载文件夹

用户从远程面板拖一个文件夹到本地面板。系统递归下载目录内容，队列中显示总体状态和当前文件。

### 场景 4：远程到远程传输

用户打开两个远程标签，将远程 A 的文件拖到远程 B。系统先下载到本地临时目录，再上传到远程 B，完成后清理临时文件。

### 场景 5：任务失败

传输过程中网络断开或权限不足。任务进入失败状态，显示错误信息，并允许用户重试。

## 第一阶段不解决的问题

- 不保证所有 FTP 服务器的非标准 LIST 格式都能完美解析。
- 不实现服务器到服务器直传。
- 不实现复杂权限递归编辑。
- 不实现 SSH 命令终端。
- 不实现密码安全存储。

这些问题不影响第一阶段验证产品主流程。
