# 01-第一阶段MVP

关联：[总体技术方案](00-总体技术方案.md)、[架构与分层](02-架构与分层.md)

## MVP 目标

MVP 目标是先做出 Xftp 风格的可用主流程，而不是一次性塞满所有高级功能。

必须验证：

- 本地目录可以浏览。
- 远程目录可以浏览。
- 站点配置可以保存和加载。
- 文件可以上传和下载。
- 传输任务进入队列并显示状态。
- 基础日志能写入文件并给 UI 使用。

#### 远程文件右键菜单

V1 本地和远程文件列表只使用“详细信息”显示方式，不提供大图标、小图标、列表等显示模式切换。两侧文件面板应使用统一的菜单构建逻辑，只根据本地/远程能力差异启用不同动作。

右键菜单中的 `查看` 子菜单只保留文件树显示/隐藏功能：

```text
查看 >
  文件树
```

不提供 `图标排列方式` 子菜单。排序通过点击文件列表表头完成，行为应符合常规文件资源管理器逻辑：

- 点击 `名称`、`大小`、`类型`、`修改时间` 等表头进行排序。
- 再次点击同一表头切换升序/降序。
- 文件夹优先显示，文件在后；同类项目再按当前列排序。
- 不在右键菜单中提供 `全选` 和 `刷新`，全选使用 `Ctrl+A`，刷新使用工具栏或地址栏刷新按钮。

本地和远程文件列表空白处右键菜单：

```text
查看 >
  文件树
复制文件夹路径
新建 >
  新建文件夹
  新建文件
属性
```

本地文件列表选中文件或目录时右键菜单：

```text
打开
上传
重命名
删除
复制路径
属性
```

本地删除必须保留确认。V1 不做复制、粘贴、剪切、打开方式和递归目录传输。

远程文件列表选中文件或目录时右键菜单：

```text
下载
重命名
删除
复制路径
属性
```

目录项可额外提供 `进入`。删除远程项目必须保留确认，V1 不做递归删除目录。

### 多远程会话

远程会话按标签页组织。每个远程标签页独立持有：

- 会话 id。
- 站点配置。
- 远程文件系统实例。
- 远程文件面板。
- 当前远程路径。
- 连接状态。
- 显示名称。

快速连接和 Session Manager 打开站点时，会创建新的远程标签页，而不是覆盖唯一远程面板。断开、刷新、新建、删除、重命名、上传、下载都作用于当前激活远程标签页。

底部传输队列保持全局显示，传输任务必须记录所属远程会话 id 和会话名称，便于多个远程标签页同时存在时追踪任务来源。

## 验收场景

1. 用户打开软件，看到左本地、右远程、会话管理器、传输队列和日志区域。
2. 用户保存一个站点配置，重启后仍能加载。
3. 用户连接 FTP 或 SFTP，远程面板显示目录。
4. 用户从本地拖文件到远程，生成上传任务并完成。
5. 用户从远程拖文件到本地，生成下载任务并完成。
6. 连接失败或传输失败时，UI 和日志都能显示可理解的错误。
