# DirBridge v0.5.0 版本归档

关联：[[../版本规划]]、[[../01-第一阶段MVP]]、[[../02-架构与分层]]

## 版本定位

v0.5.0 是会话管理增强版，目标是把 v0.4.1 之后的站点管理、多会话体验和 Session Manager 状态同步收敛成一个可归档阶段。

## 功能变更

- 新增独立站点属性编辑对话框，支持新建、编辑、删除站点。
- `SiteProfile` 新增 `group` 字段，站点可按分组显示。
- Session Manager 支持站点分组重命名，组内站点会跟随更新。
- 新增 `UserSettings` 和 `SettingsStore`，通过 `config/settings.json` 保存最近会话记录。
- 最近会话记录只保存站点 id、上次远程路径、显示名称和打开时间，不保存密码副本。
- 当前远程 Tab 与 Session Manager 状态同步，当前会话和断开状态能在树中体现。
- 远程会话 Tab 支持关闭按钮，关闭一个会话不会影响其他远程会话。
- 连接失败、默认目录加载失败、站点缺失和配置读写失败提示更明确。
- 应用版本号更新为 `0.5.0`。

## 版本边界

- 不做启动自动重连。
- 不做启动恢复远程 Tab。
- 不引入安全密码存储，仍沿用 MVP 阶段明文密码策略。
- 不处理目录传输聚合进度，留到 v0.6.0。
